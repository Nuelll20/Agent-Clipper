# Hermes Artifact Foundation

Version:
Hermes Editor V2.1 - Milestone 1

Purpose:
Provide versioned source-of-truth artifacts for Hermes pipeline.

Artifacts:
- job-manifest
- media-probe
- transcript
- semantic-plan
- EDL
- scene-graph
- QA-report

All artifacts must contain:
- schema_version
- producer_version
- source_fingerprint
- config_fingerprint
- created_at
- upstream_artifacts
